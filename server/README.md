# Рейтинг «Под солнцем»

Cloudflare Worker плюс база D1. Две ручки: клиент шлёт свой результат и
получает обратно топ-20 и своё место.

Игра остаётся играбельной без всего этого. Не задан адрес, нет сети, сервер
молчит — просто нет таблицы. Ограничение «открывается двойным кликом» уцелело.

## Что нужно от тебя

**Аккаунт Cloudflare** (бесплатного тарифа хватает с большим запасом) и один
раз выполнить шаги ниже. Аккаунты я заводить не могу, пароли и токены —
не трогаю.

### 1. Поставить wrangler и войти

```
npm install -g wrangler
wrangler login
```

Откроется браузер, там подтвердишь доступ.

### 2. Завести базу

```
cd server
wrangler d1 create pod-solncem-rating
```

Команда напечатает `database_id`. Вписать его в `wrangler.toml` вместо
`ВПИШИ_СЮДА_ID_ИЗ_wrangler_d1_create`.

Создать таблицу:

```
wrangler d1 execute pod-solncem-rating --remote --file=schema.sql
```

### 3. Положить токен бота в секрет

```
wrangler secret put BOT_TOKEN
```

Команда спросит токен — вставить тот, что выдал BotFather. Он уйдёт в
хранилище секретов Cloudflare, в репозиторий не попадёт и в коде не появится.

Токен нужен потому, что подпись `initData` считается на нём: сервер обязан
убедиться, что запрос пришёл от конкретного аккаунта Telegram, а не от кого
угодно с curl.

### 4. Выложить

```
wrangler deploy
```

Напечатает адрес вида `https://pod-solncem-rating.<твой>.workers.dev`.

### 5. Вписать адрес в игру

В `js/rating.js`, первая значимая строка:

```js
const RATING_URL = 'https://pod-solncem-rating.твой.workers.dev';
```

Потом обязательно `node tools/stamp.js`, коммит и push.

## Проверить, что работает

```
curl https://адрес-воркера/top
```

Должен ответить `{"total":0,"top":[]}`. Дальше открой игру в Telegram,
зайди на «Профиль» — там появится таблица.

## Ручки

**`POST /sync`** — `{ initData, score, runs, path }` → `{ total, top, me }`

Проверяет подпись, обновляет строку игрока, возвращает топ-20 и своё место.

**`GET /top`** → `{ total, top }`

Только чтение, без подписи. Удобно для проверки.

## Правила, зашитые в сервер

- Подпись `initData` обязательна, сверяется с секретом бота.
- `auth_date` старше суток не принимается.
- Результат только растёт: откатить свой счёт нельзя.
- Не чаще одного обновления в 10 секунд от игрока.
- Имя берётся из профиля Telegram и обрезается до 40 символов.

## Чего сервер не умеет

**Он не проверяет, честно ли заработан результат.** Счёт считает клиент, и
подпись доказывает, кто прислал, а не что прислали. Человек, который откроет
консоль, впишет себе любую сумму.

Чтобы этого не было, нужно считать экономику на сервере — то есть переписать
игру в клиент-серверную. Для игры без игроков это несоразмерно. Если накрутки
начнутся, дешёвая полумера — ограничить прирост за единицу времени: сервер
знает `updated` и может отвергать скачки, невозможные по темпу игры.

Это стоит знать заранее, чтобы не удивляться первому же миллиардеру.
